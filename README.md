# AI-Based-Cryptocurrency-Risk-Analysis-Using-Volatility-and-Regime-Switching
CryptoRisk AI is an AI-driven cryptocurrency risk analysis platform using GARCH, Markov Regime Switching, and volatility detection models to analyze market risk. Built with Binance API, Streamlit, and Plotly, it provides real-time risk scores, heatmaps, and AI-generated insights for major crypto assets.
